项目概览

从需求定义、真实采集到可分发 Windows Demo 的完整实现。

问题

缺陷现场容易丢失

试玩者往往只能回忆 Bug 发生的大致时间，研发收到反馈后需要从完整日志和长时间性能记录中反复查找。

方案

时间段驱动证据截取

工具持续滚动采集最近 30 分钟；提交时只选择开始与结束时间，自动生成对应性能、日志和来源状态。

结果

QA 与研发直接查看

离线报告同时提供反馈信息、性能曲线、日志事件、原始证据与数据完整性说明，减少往返补问。

✓

公开展示数据边界

保留诊断价值，同时避免暴露无关个人信息。

三份报告保留真实采集的性能数据、日志事件、进程、主机和会话信息；仅移除用户名及本机绝对路径。游戏文件、构建缓存和与展示无关的个人数据不会公开。Demo 不注入游戏进程，不读取或修改游戏内存，也不规避反作弊。
